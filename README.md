# SMART DC Delivery Challan

KGR FABTEK delivery challan manager. The app is a static single-page website deployed with GitHub Pages.

## Data storage

Challan records and masters are stored only in the browser that created them. They are not shared with other visitors or uploaded to a server. Use the in-app backup export to keep a copy.

## Deployment

GitHub Pages serves `index.html` from the root of the `main` branch.
